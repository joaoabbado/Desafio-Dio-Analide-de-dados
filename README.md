📊 Dashboard de Vendas – Planos Xbox (Excel)
📌 Descrição do Projeto

Este projeto consiste na criação de um dashboard de vendas de planos do Xbox, desenvolvido no Microsoft Excel, com o objetivo de analisar e visualizar dados de forma clara, rápida e eficiente.

O dashboard foi construído a partir de uma base de dados de vendas, utilizando tabelas dinâmicas para gerar informações específicas que alimentam os indicadores e gráficos apresentados.

🎯 Objetivo

Analisar o desempenho das vendas de planos Xbox

Facilitar a visualização de métricas importantes

Transformar dados brutos em informações estratégicas

🛠️ Ferramentas Utilizadas

Microsoft Excel

Tabelas Dinâmicas

Gráficos Dinâmicos

Segmentações de Dados (filtros interativos)

📈 Funcionalidades do Dashboard

Visão geral das vendas de planos Xbox

Indicadores de total de vendas 

Análise por período, tipo de plano ou categoria

Filtros interativos para facilitar a análise dos dados

🔎 Processo de Desenvolvimento

Organização e tratamento da base de dados

Criação de tabelas dinâmicas para gerar dados específicos

Construção de gráficos a partir das tabelas dinâmicas

Montagem do dashboard final com layout visual e intuitivo

📚 Aprendizados

Uso prático de tabelas dinâmicas para análise de dados

Criação de dashboards no Excel

Organização e visualização de informações para tomada de decisão

🚀 Possíveis Melhorias Futuras

Inclusão de mais métricas e KPIs

Automatização da atualização dos dados

Integração com outras fontes de dados
